CogVideoX 是智谱 AI 联合清华大学搞的开源视频生成模型，GitHub 星标 12.9K。它干的事情很简单：你输入一段文字描述，它直接给你吐出一段 6-10 秒的视频。

核心能力：三种模式，覆盖剪辑师 80% 的补画面需求
CogVideoX 支持三种视频生成任务。

文生视频（T2V）：输入英文提示词，输出 6-10 秒视频。这是最常用模式，口播缺 B-roll 时直接用。

图生视频（I2V）：给一张图片当首帧，AI 基于这张图往后续写动态画面。首帧一致性高，适合把静态封面变成动态视频。

视频续写（V2V）：已有视频太短？让它接着往后画。相当于 AI 帮你"加戏"。

三种模式覆盖了剪辑师最常见的补画面场景。不用再翻素材库找"差不多"的画面了——直接描述你要什么，AI 给你现造。
显存门槛：比腾讯的方案低 16 倍
这是 CogVideoX 最狠的差异化。

腾讯的 HunyuanVideo-I2V 最低要 60GB 显存，A100 80G 起步。CogVideoX-2B 量化版只要 3.6GB。差距 16 倍。

意味着什么？意味着你不用租服务器，不用买专业显卡。RTX 3060 12GB 就能跑 5B 模型，甚至 Colab 免费版 T4 GPU 直接用。
对于独立创作者和小团队来说，这基本消除了硬件门槛。以前"AI 视频生成"是大厂的专属玩具，现在 3000 块的显卡就是你的渲染农场。

实测表现：4G 显存真的能打吗？
回到开头的问题——这么小的模型，画质到底行不行？

B 站 UP 主"黎黎原上咩"（2.3 万播放）实测后评价："无论是文生视频还是图生视频，效果都可圈可点"，认为 CogVideoX-5B 是"ComfyUI 上 AI 视频生成领域里的上等马"。

横向对比方面，B 站 UP 主"青龙圣者"（6.9 万粉丝）对比了四款开源视频模型：HunyuanVideo 画质最佳但要 60G 显存，Wan2.2 功能最全，LTX 速度最快，CogVideoX 在画面一致性方面表现突出，特别是图生视频场景。

但也有不足。GitHub Issue #797 反馈 LoRA 微调后视频过曝模糊；Issue #773 指出 Scheduler 配置不一致会导致输出质量差异；生成速度方面，1.5 版本在 A100 上生成 5 秒视频需要约 1000 秒，确实偏慢。

另外，仅支持英文提示词是中文用户最大的障碍。不过项目自带 convert_demo.py，用 GLM-4 自动翻译，实际使用影响不大。
生态方面也跟得上。ComfyUI 集成、LoRA 微调、CogKit 一站式工具、15+ 个社区衍生项目。清影平台（chatglm.cn/video）可以直接在线体验。

优缺点：门槛极低，但天花板也不高
优点：

3.6GB 显存起步，消费级显卡全覆盖
三种任务模式（T2V/I2V/V2V），剪辑师最常用的功能都有
生态最全：ComfyUI、LoRA、量化推理、并行加速全支持
Colab 免费版零成本试用，pip install 一键安装
短板：

仅支持英文提示词，中文用户需要 LLM 翻译
分辨率最高 768p，无法生成 1080p/4K
视频最长 10 秒，长视频需要多次续写拼接
5B 模型许可证非 Apache 2.0，商用需注意
门槛和生态是它的护城河，画质和时长是它的天花板。
说白了，CogVideoX 是"够用级"工具——足够日常剪辑补画面，但别指望它出电影级素材。

落地门槛：有 Python 就能跑
上手路径有两条。

路径 A：本地 Diffusers。pip install 一条命令装完，Gradio Web UI 直接用。RTX 3060 跑 5B 模型，90 秒出一段 6 秒视频。

路径 B：Colab 免费版。零安装，打开 Notebook 点运行就行。T4 免费 GPU 大概 90 秒出一段。适合先试水，觉得好再本地部署。
提示词需要英文，但不用担心——项目自带 convert_demo.py，用 GLM-4 自动把中文转成训练格式的长提示词。一句话就能搞定。

实验室锐评： 以前靠手感找素材，现在靠一行字造画面。这根本不是工具升级，是 B-roll 采购逻辑的底层重写。

实验室锐评
CogVideoX 最适合两类人：一是日常需要补 B-roll 但不想花时间翻素材库的剪辑师，二是想低成本试水 AI 视频生成的独立创作者。

不适合的场景很明确：需要 4K 画质的商业项目、需要长镜头的叙事内容、需要实时生成的直播场景。

4G 显存出 6 秒视频，以前这事儿要 60GB 显存的 A100 才能干。门槛降维到消费级显卡，这不是技术优化，是行业生存格局的物理级改写。
