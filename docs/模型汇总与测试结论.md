## 二、测试结论（用户评价）

### 无参考图质量排序
```
Animagine / PuLID+Animagine  >  SDXL base（PuLID/InstantID） >  FLUX.2-klein
     ⭐⭐⭐⭐                          ⭐⭐⭐                       ⭐⭐
```

### 有参考图质量排序
```
PuLID+Animagine ≈ PuLID(SDXL)  >  InstantID
    ⭐⭐⭐⭐              ⭐⭐⭐⭐           ⭐⭐（脸崩）
```
